## Grounding Principles Applied

1. **Duplicate:** Both complaints report the same physical defect or incident at the same location within hours.
2. **Related:** Distinct but causally connected defects arising from a common documented physical event (vehicle collision, utility burst, overflow contamination). Proximity alone without explicit causal evidence is NOT sufficient.
3. **Independent:** Distinct defects with no documented common cause, even if co-located or occurring concurrently.
